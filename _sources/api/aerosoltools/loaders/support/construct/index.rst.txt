aerosoltools.loaders.support.construct
======================================

.. py:module:: aerosoltools.loaders.support.construct

.. autoapi-nested-parse::

   Shared object-construction helpers for the size-resolved loaders.

   The 2-D loaders all finish the same way: build the class, set the same handful
   of ``_meta`` fields (instrument / bin axis / serial / unit / dtype / density),
   convert to number concentration and undo any ``/dlogDp`` normalization. This
   helper centralises that tail so a loader doesn't repeat it (and doesn't reach
   into the core private conversion methods directly).

.. py:function:: build_2d(data, *, bin_edges, bin_mids, instrument, serial_number, unit, dtype, density = 1.0, cls = None, extra_meta = None, to_number = True, unnormalize = True)

   Construct a size-resolved object and finish loading it.

   Builds ``cls(data)`` (default :class:`Aerosol2D`), writes the canonical
   metadata, then — unless disabled — converts the distribution to number
   concentration and removes any ``/dlogDp`` normalization, matching what the
   loaders did inline.

   :param data: The assembled ``DataFrame`` (Datetime index or column, Total_conc,
                one column per size bin) the class expects.
   :param bin_edges / bin_mids: Size-bin edges and midpoints (nm).
   :param instrument: Instrument name for ``_meta["instrument"]``.
   :param serial_number: Instrument serial number.
   :param unit: Concentration unit string.
   :param dtype: Distribution dtype string (e.g. ``"dN"``, ``"dM/dlogDp"``).
   :param density: Particle density in g/cm³ (default 1.0).
   :param cls: Concrete class to instantiate (e.g. :class:`ELPI`); defaults to
               :class:`Aerosol2D`.
   :param extra_meta: Optional extra metadata merged into ``_meta`` (e.g. the ELPI
                      charger/cutpoint fields) *before* the conversion runs.
   :param to_number: Convert to number concentration (``_convert_to_number_
                     concentration``) after construction. Default ``True``.
   :param unnormalize: Undo ``/dlogDp`` normalization after construction. Default
                       ``True``.

   :returns: The constructed, fully-populated object.


.. py:function:: build_1d(data, *, instrument, serial_number, unit=None, dtype = None, cls = None, extra_meta = None)

   Construct a 1-D (time-series) object and set its canonical metadata.

   The 1-D / non-particle loaders finish by building the class and writing a
   small, mostly-shared set of ``_meta`` fields; this centralises that tail.
   Unlike :func:`build_2d` there is no size axis and no number/normalization
   conversion. ``unit`` may be a string or a per-channel ``dict`` (multi-channel
   instruments), and ``dtype`` is optional (some non-particle classes carry it
   per channel via ``extra_meta`` instead).

   :param data: The assembled ``DataFrame`` the class expects.
   :param instrument: Instrument name for ``_meta["instrument"]``.
   :param serial_number: Instrument serial number.
   :param unit: Concentration unit string, or a per-channel ``{col: unit}`` dict.
                Omitted from ``_meta`` when ``None``.
   :param dtype: Distribution/quantity dtype string; omitted when ``None``.
   :param cls: Concrete class to instantiate (e.g. :class:`Gas1D`,
               :class:`Partector`); defaults to :class:`Aerosol1D`.
   :param extra_meta: Optional extra metadata merged into ``_meta`` *before* the
                      canonical fields (so instrument/serial/unit/dtype win on collision).

   :returns: The constructed, populated object.
