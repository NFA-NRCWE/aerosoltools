# Examples

Worked examples using `aerosoltools`, each covering one theme. They are written
to be read in order — the later ones assume the vocabulary of the earlier ones —
but each stands on its own if you already know the basics.

Every notebook is executed when these docs are built, so the outputs below were
produced by the version of the package you are reading about.

**Start here:** [1 — Loading data](01-loading-data.ipynb) covers getting a file
off disk and understanding what you get back.
